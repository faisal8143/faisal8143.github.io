  ==========================================================================
  NORTHWIND LEARNING | ENGAGEMENT SCORING QUERY
  Author: Faisal Irfan | github.com/faisal8143
  ==========================================================================
  Automation Studio query: engagement score for the last 90 days
  Target DE: Engagement_Score_90d (Overwrite)
  Primary key: SubscriberKey

  Score = opens x 1 + clicks x 3, excluding bounced/unsubscribed subscribers.
  Uses system data views (_Open, _Click, _Bounce, _Subscribers).
*/

SELECT
    s.SubscriberKey,
    s.EmailAddress,
    ISNULL(o.Opens, 0)                                   AS Opens90d,
    ISNULL(c.Clicks, 0)                                  AS Clicks90d,
    ISNULL(o.Opens, 0) * 1 + ISNULL(c.Clicks, 0) * 3     AS EngagementScore,
    CASE
        WHEN ISNULL(c.Clicks, 0) >= 3                    THEN 'Hot'
        WHEN ISNULL(o.Opens, 0) >= 2 OR c.Clicks >= 1    THEN 'Warm'
        ELSE 'Cold'
    END                                                  AS Segment,
    GETDATE()                                            AS CalculatedAt
FROM _Subscribers s
LEFT JOIN (
    SELECT SubscriberKey, COUNT(DISTINCT JobID) AS Opens
    FROM _Open
    WHERE EventDate >= DATEADD(DAY, -90, GETDATE())
      AND IsUnique = 1
    GROUP BY SubscriberKey
) o ON o.SubscriberKey = s.SubscriberKey
LEFT JOIN (
    SELECT SubscriberKey, COUNT(DISTINCT JobID) AS Clicks
    FROM _Click
    WHERE EventDate >= DATEADD(DAY, -90, GETDATE())
      AND IsUnique = 1
    GROUP BY SubscriberKey
) c ON c.SubscriberKey = s.SubscriberKey

  NORTHWIND LEARNING | DEDUPLICATE ENQUIRIES (LATEST PER SUBSCRIBER)
  Author: Faisal Irfan | github.com/faisal8143
  ==========================================================================
  Automation Studio query. Source: Course_Enquiries_Raw (all form fills)
  Target: Course_Enquiries (Overwrite, PK SubscriberKey)

  Keeps only each subscriber's most recent enquiry, normalises email case,
  and drops rows without a valid-looking email address.

SELECT
    LOWER(LTRIM(RTRIM(e.EmailAddress)))  AS SubscriberKey,
    LOWER(LTRIM(RTRIM(e.EmailAddress)))  AS EmailAddress,
    e.FirstName,
    e.CourseCode,
    e.CourseName,
    e.OptIn,
    e.EnquiryDate
FROM (
    SELECT
        r.*,
        ROW_NUMBER() OVER (
            PARTITION BY LOWER(LTRIM(RTRIM(r.EmailAddress)))
            ORDER BY r.EnquiryDate DESC
        ) AS rn
    FROM Course_Enquiries_Raw r
    WHERE r.EmailAddress LIKE '%_@_%._%'
) e
WHERE e.rn = 1

  Author: Faisal Irfan | github.com/faisal8143

  Posts a custom website form to a Pardot (Account Engagement) form
  handler without leaving the page, while keeping Pardot's visitor
  tracking (cookies) and completion actions working.
    - Client-side validation with accessible error messages
    - Submits via a hidden iframe (form handlers do not support CORS)
    - UTM and GCLID values captured into hidden fields for attribution
    - Prevents double submits; shows a success state
  ==========================================================================
*/
(function () {
  var HANDLER_URL = "https://go.example.edu/l/000000/2026-10-30/abcde"; /* form handler endpoint */
  var form = document.getElementById("enquiry-form");
  if (!form) return;

  /* 1. Capture attribution parameters into hidden fields */
  var params = new URLSearchParams(window.location.search);
  ["utm_source", "utm_medium", "utm_campaign", "utm_content", "gclid"].forEach(function (key) {
    var field = form.querySelector('[name="' + key + '"]');
    if (field && params.get(key)) field.value = params.get(key);
  });

  /* 2. Hidden iframe target keeps the visitor on the page */

  frame.name = "pardot-target";
  frame.title = "Form submission";
  frame.hidden = true;

    var id = input.id + "-error";
    var el = document.getElementById(id);
    if (!el) {
      el = document.createElement("p");
      el.id = id;
      el.className = "field-error";
      input.insertAdjacentElement("afterend", el);
    }
    el.textContent = message;
    input.setAttribute("aria-invalid", message ? "true" : "false");
    input.setAttribute("aria-describedby", id);
  }

    var ok = true;
    var email = form.elements.email;
    var name = form.elements.first_name;
    setError(name, name.value.trim() ? "" : "Please enter your first name.");
    setError(email, /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email.value) ? "" : "Please enter a valid email address.");
    if (!name.value.trim() || !/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email.value)) ok = false;

      form.hidden = true;
      var done = document.getElementById("enquiry-success");
      if (done) { done.hidden = false; done.focus(); }
    }, { once: true });
  });

# AMPscript patterns I ship

**Author:** Faisal Irfan · [github.com/faisal8143](https://github.com/faisal8143)
**Brand:** Northwind Learning (fictional, for demonstration)

Production patterns, written out with the reasoning. Every one of these exists
because something went wrong in a real send once.

---

## 1. No lookup without a fallback

The single most common cause of an embarrassing send is a blank personalisation
value. Every `Lookup` gets a default, and the default is written to read as a
complete sentence.

```
SET @firstName = AttributeValue("FirstName")
IF Empty(@firstName) THEN
  SET @firstName = "there"
ELSE
  SET @firstName = ProperCase(Trim(@firstName))
ENDIF
```

`Trim` before `ProperCase`, not after: a leading space makes `ProperCase`
capitalise the space and leave the first letter lowercase.

---

## 2. Most recent row, not just any row

`LookupRows` returns rows in no guaranteed order. If you want the latest
enquiry, say so.

```
SET @rows = LookupOrderedRows("Course_Enquiries", 1, "EnquiryDate DESC",
                              "SubscriberKey", _subscriberkey)
IF RowCount(@rows) > 0 THEN
  SET @row  = Row(@rows, 1)
  SET @name = Field(@row, "CourseName")
ELSE
  SET @name = "your chosen course"
ENDIF
```

Always guard with `RowCount` before `Row`. Calling `Row` on an empty set
throws and kills the whole send, not just that subscriber's content block.

---

## 3. Dates: format at the edge, compute in the middle

Store and compare raw dates. Format only at the point of output, and give the
locale explicitly so an Australian send does not render US dates.

```
SET @closeRaw  = Lookup("Term_Config", "CloseDate", "IsCurrent", "true")
SET @daysLeft  = DateDiff(Now(), @closeRaw, "D")
SET @closeDate = FormatDate(@closeRaw, "d MMMM yyyy", "", "en-AU")
```

`DateDiff(Now(), …)` counts from the current timestamp, so a deadline stored
at midnight reads one day short. Store deadlines at end of day.

---

## 4. Tiered urgency instead of one static line

```
IF @daysLeft <= 7 THEN
  SET @urgency = "closing"
```

## 5. Conditional HTML, not conditional variables

Gate the markup itself. An `IF` opened in one block closes in a later one, and
everything between them is what gets conditionally rendered.

```
%%[ IF @isReturning == "true" THEN ]%%
  <div class="welcome-back">Your credits carry over automatically.</div>
%%[ ELSE ]%%
  <p>New to Northwind? Here is how your first term works.</p>
%%[ ENDIF ]%%
```

Building two strings in variables and outputting one works, but it puts HTML
inside AMPscript where no one will find it to edit later.

## 6. Loop a row set for line items

```
SET @items = LookupRows("Cart_Items", "SubscriberKey", _subscriberkey)
SET @count = RowCount(@items)

IF @count > 0 THEN
  FOR @i = 1 TO @count DO
    SET @item = Row(@items, @i)
%%[ ]%%
    <tr>
      <td>%%=v(Field(@item, "ProductName"))=%%</td>
      <td align="right">%%=FormatNumber(Field(@item, "Price"), "C")=%%</td>
    </tr>
%%[
  NEXT @i
ENDIF
]%%
```

Cap the loop. A data error that returns 40,000 rows will otherwise time the
send out rather than fail loudly.

## 7. Tracked links, built once

```
SET @ctaUrl = Concat("https://example.edu/apply",
                     "?course=", URLEncode(@courseCode, 1, 1),
                     "&utm_source=sfmc&utm_medium=email",
                     "&utm_campaign=", URLEncode(emailname_, 1, 1))
```

Then in the HTML: `href="%%=RedirectTo(@ctaUrl)=%%"` with an `alias` attribute
so the click report reads as link names, not a list of identical URLs.

`URLEncode(value, 1, 1)` — the second argument encodes reserved characters, the
third encodes the `%` sign itself. Miss them and a course code with a space
silently breaks the landing page.

## 8. Treat booleans as strings

Data Extension boolean fields come back as the strings `"True"`/`"False"`, and
the casing varies by how the row was written.

```
SET @isReturning = Lowercase(Lookup("Student_Status", "IsReturning",
                                    "SubscriberKey", _subscriberkey))
IF @isReturning == "true" THEN
```

Comparing against the unquoted `true` keyword works sometimes and fails
silently the rest of the time. Lowercase it and compare against a string.

## 9. Fail soft, log hard

In a CloudPage, wrap anything that touches data so a visitor never sees a stack
trace, and write the error somewhere you will actually look.

```
SET @ok = true
```

## 10. Make the send self-documenting

A one-line comment block at the top of every template, naming the Data
Extensions it reads and who wrote it, saves the next developer twenty minutes.
The footer of a test send carrying `segment`, `score` and the key variable
values turns QA from guesswork into reading.

```
<span style="color:#94A3B8">
  Segment: %%=v(@segment)=%% · score %%=v(@score)=%% · days to close %%=v(@daysLeft)=%%
</span>
```

Strip it with an `IF` on a `IsTest` attribute rather than by hand, because by
hand means it ships to production once.

  ==========================================================================
  Automation Studio query. Builds the sendable audience for a campaign by
  combining subscriber attributes with every suppression rule in one pass.

  Source      Course_Enquiries, Student_Status, Subscriber_Preferences,
              Suppression_Manual, _Subscribers, _Bounce, _Unsubscribe, _Sent
  Target      Campaign_Audience (Overwrite)
  Primary key SubscriberKey

  Why one query rather than a chain of filters: a filter chain hides WHY a
  subscriber was dropped. This keeps the reason on the row, so the count can
  be explained to a client without re-running anything.
*/

WITH latest_enquiry AS (
    /* One row per subscriber: the most recent enquiry only */
    SELECT
        SubscriberKey,
        CourseCode,
        CourseName,
        Fee,
        EnquiryDate
    FROM (
        SELECT
            e.*,
            ROW_NUMBER() OVER (PARTITION BY e.SubscriberKey
                               ORDER BY e.EnquiryDate DESC) AS rn
        FROM Course_Enquiries e
        WHERE e.EmailAddress LIKE '%_@_%._%'
    ) ranked
    WHERE rn = 1
),

fatigue AS (
    /* Anyone who already received 3+ sends in the last 7 days */
    SELECT SubscriberKey, COUNT(*) AS Sends7d
    FROM _Sent
    WHERE EventDate >= DATEADD(DAY, -7, GETDATE())
    GROUP BY SubscriberKey
    HAVING COUNT(*) >= 3
),

suppression AS (
    /* Every reason to exclude someone, unioned, with the reason kept */
    SELECT SubscriberKey, 'Hard bounce'        AS Reason
    FROM _Bounce
    WHERE BounceCategory = 'Hard bounce'
      AND EventDate >= DATEADD(DAY, -180, GETDATE())

    UNION
    SELECT SubscriberKey, 'Unsubscribed'
    FROM _Unsubscribe

    UNION
    SELECT SubscriberKey, 'Opted out of this topic'
    FROM Subscriber_Preferences
    WHERE News = 'false'

    UNION
    SELECT SubscriberKey, 'Manual suppression'
    FROM Suppression_Manual

    UNION
    SELECT SubscriberKey, 'Send fatigue'
    FROM fatigue
)

/*
  ==========================================================================
  MINI AMPSCRIPT EVALUATOR  (browser, dependency-free)
  Author: Faisal Irfan | github.com/faisal8143
  --------------------------------------------------------------------------
  Evaluates the subset of AMPscript used by the demo template so the page can
  render a real Marketing Cloud email against different subscriber rows
  without a Marketing Cloud login.

  Supported
    blocks        %%[ ... ]%%            statement block
    inline        %%=v(@x)=%%            output an expression
    statements    SET, IF / ELSEIF / ELSE / ENDIF, FOR / NEXT
    operators     == != <> > >= < <= AND OR NOT, string concat via Concat()
    literals      "double" 'single' numbers true/false
    functions     Lookup, LookupRows, LookupOrderedRows, Row, Field, RowCount,
                  Empty, Trim, ProperCase, Uppercase, Lowercase, Concat,
                  Length, Substring, IndexOf, Replace, IIF,
                  FormatDate, FormatNumber, Now, DateDiff, DateAdd,
                  Add, Subtract, Multiply, Divide, Mod, AttributeValue,
                  URLEncode, RedirectTo, ProperCase

  Not a Marketing Cloud emulator. It covers the documented behaviour of these
  functions closely enough to preview personalisation logic, including the
  fallbacks that decide what a subscriber actually sees.
  ==========================================================================
*/
(function (global) {
  'use strict';

  /* ---------------------------------------------------------------- lexer */
  function tokenize(src) {
    var t = [], i = 0, n = src.length;
    var two = ['==', '!=', '<>', '>=', '<='];
    while (i < n) {
      var c = src[i];
      if (/\s/.test(c)) { i++; continue; }
      if (c === '/' && src[i + 1] === '*') { var e = src.indexOf('*/', i); i = e === -1 ? n : e + 2; continue; }
      if (c === '"' || c === "'") {
        var q = c, s = ''; i++;
        while (i < n && src[i] !== q) { s += src[i++]; }
        i++; t.push({ k: 'str', v: s }); continue;
      }
      if (/[0-9]/.test(c)) {
        var num = ''; while (i < n && /[0-9.]/.test(src[i])) num += src[i++];
        t.push({ k: 'num', v: parseFloat(num) }); continue;
      }
      if (c === '@' || /[A-Za-z_]/.test(c)) {
        var w = ''; if (c === '@') { w = '@'; i++; }
        while (i < n && /[A-Za-z0-9_]/.test(src[i])) w += src[i++];
        t.push({ k: w[0] === '@' ? 'var' : 'word', v: w }); continue;
      }
      var pair = src.substr(i, 2);
      if (two.indexOf(pair) !== -1) { t.push({ k: 'op', v: pair }); i += 2; continue; }
      t.push({ k: 'op', v: c }); i++;
    }
    return t;
  }

  /* --------------------------------------------------------------- parser */
  function Parser(tokens) { this.t = tokens; this.i = 0; }
  Parser.prototype.peek = function (o) { return this.t[this.i + (o || 0)]; };
  Parser.prototype.next = function () { return this.t[this.i++]; };
  Parser.prototype.isWord = function (w) {
    var p = this.peek();
    return p && p.k === 'word' && p.v.toUpperCase() === w;
  };
  Parser.prototype.eatOp = function (v) {
    var p = this.peek();
    if (p && p.k === 'op' && p.v === v) { this.i++; return true; }
    return false;
  };

  Parser.prototype.parseBlock = function (stops) {
    var out = [];
    while (this.i < this.t.length) {
      var p = this.peek();
      if (p.k === 'word' && stops.indexOf(p.v.toUpperCase()) !== -1) break;
      out.push(this.parseStatement());
    }
    return out;
  };

  Parser.prototype.parseStatement = function () {
    var p = this.peek();
    if (p.k === 'word') {
      var w = p.v.toUpperCase();
      if (w === 'SET') {
        this.next();
        var target = this.next();            // @var
        this.eatOp('=');
        return { t: 'set', name: target.v, expr: this.parseExpr() };
      }
      if (w === 'IF') {
        this.next();
        var branches = [], cond = this.parseExpr();
        if (this.isWord('THEN')) this.next();
        branches.push({ cond: cond, body: this.parseBlock(['ELSEIF', 'ELSE', 'ENDIF']) });
        while (this.isWord('ELSEIF')) {
          this.next();
          var c2 = this.parseExpr();
          if (this.isWord('THEN')) this.next();
          branches.push({ cond: c2, body: this.parseBlock(['ELSEIF', 'ELSE', 'ENDIF']) });
        }
        var els = null;
        if (this.isWord('ELSE')) { this.next(); els = this.parseBlock(['ENDIF']); }
        if (this.isWord('ENDIF')) this.next();
        return { t: 'if', branches: branches, els: els };
      }
      if (w === 'FOR') {
        this.next();
        var v = this.next().v;
        this.eatOp('=');
        var from = this.parseExpr();
        var dir = 'TO';
        if (this.isWord('TO')) this.next(); else if (this.isWord('DOWNTO')) { this.next(); dir = 'DOWNTO'; }
        var to = this.parseExpr();
        if (this.isWord('DO')) this.next();
        var body = this.parseBlock(['NEXT']);
        if (this.isWord('NEXT')) { this.next(); if (this.peek() && this.peek().k === 'var') this.next(); }
        return { t: 'for', v: v, from: from, to: to, dir: dir, body: body };
      }
    }
    return { t: 'expr', expr: this.parseExpr() };    // bare call, e.g. OutputLine
  };

  /* expressions: OR < AND < compare < concat/add < unary < primary */
  Parser.prototype.parseExpr = function () { return this.parseOr(); };
  Parser.prototype.parseOr = function () {
    var l = this.parseAnd();
    while (this.isWord('OR')) { this.next(); l = { t: 'bin', op: 'OR', l: l, r: this.parseAnd() }; }
    return l;
  };
  Parser.prototype.parseAnd = function () {
    var l = this.parseCmp();
    while (this.isWord('AND')) { this.next(); l = { t: 'bin', op: 'AND', l: l, r: this.parseCmp() }; }
    return l;
  };
  Parser.prototype.parseCmp = function () {
    var l = this.parseAdd(), p = this.peek();
    while (p && p.k === 'op' && ['==', '!=', '<>', '>', '>=', '<', '<='].indexOf(p.v) !== -1) {
      this.next();
      l = { t: 'bin', op: p.v, l: l, r: this.parseAdd() };
      p = this.peek();
    }
    return l;
  };
  Parser.prototype.parseAdd = function () {
    var l = this.parseUnary(), p = this.peek();
    while (p && p.k === 'op' && (p.v === '+' || p.v === '-')) {
      this.next();
      l = { t: 'bin', op: p.v, l: l, r: this.parseUnary() };
      p = this.peek();
    }
    return l;
  };
  Parser.prototype.parseUnary = function () {
    if (this.isWord('NOT')) { this.next(); return { t: 'not', e: this.parseUnary() }; }
    return this.parsePrimary();
  };
  Parser.prototype.parsePrimary = function () {
    var p = this.next();
    if (!p) return { t: 'lit', v: '' };
    if (p.k === 'str') return { t: 'lit', v: p.v };
    if (p.k === 'num') return { t: 'lit', v: p.v };
    if (p.k === 'var') return { t: 'ref', name: p.v };
    if (p.k === 'op' && p.v === '(') { var e = this.parseExpr(); this.eatOp(')'); return e; }
    if (p.k === 'word') {
      var up = p.v.toUpperCase();
      if (up === 'TRUE') return { t: 'lit', v: true };
      if (up === 'FALSE') return { t: 'lit', v: false };
      if (this.peek() && this.peek().k === 'op' && this.peek().v === '(') {
        this.next();
        var args = [];
        if (!(this.peek() && this.peek().k === 'op' && this.peek().v === ')')) {
          args.push(this.parseExpr());
          while (this.eatOp(',')) args.push(this.parseExpr());
        }
        this.eatOp(')');
        return { t: 'call', name: p.v, args: args };
      }
      return { t: 'lit', v: p.v };
    }
    return { t: 'lit', v: '' };
  };

  /* ------------------------------------------------------------ functions */
  var MONTHS = ['January','February','March','April','May','June','July',
                'August','September','October','November','December'];

  function toStr(v) { return v === null || v === undefined ? '' : String(v); }
  function toNum(v) { var n = parseFloat(v); return isNaN(n) ? 0 : n; }
  function truthy(v) {
    if (v === true) return true;
    if (v === false || v === null || v === undefined) return false;
    var s = String(v).toLowerCase();
    return !(s === '' || s === 'false' || s === '0');
  }
  function parseDate(v) {
    if (v instanceof Date) return v;
    var d = new Date(v);
    return isNaN(d.getTime()) ? new Date() : d;
  }
  function fmtDate(d, pattern) {
    d = parseDate(d);
    var pad = function (x) { return x < 10 ? '0' + x : '' + x; };
    var map = {
      'yyyy': d.getFullYear(), 'yy': String(d.getFullYear()).slice(-2),
      'MMMM': MONTHS[d.getMonth()], 'MMM': MONTHS[d.getMonth()].slice(0, 3),
      'MM': pad(d.getMonth() + 1), 'M': d.getMonth() + 1,
      'dddd': ['Sunday','Monday','Tuesday','Wednesday','Thursday','Friday','Saturday'][d.getDay()],
      'dd': pad(d.getDate()), 'd': d.getDate(),
      'HH': pad(d.getHours()), 'mm': pad(d.getMinutes())
    };
    return String(pattern || 'M/d/yyyy').replace(
      /yyyy|yy|MMMM|MMM|MM|M|dddd|dd|d|HH|mm/g, function (m) { return map[m]; });
  }

  function makeFns(ctx) {
    var F = {};
    F.lookup = function (de, col, k1, v1, k2, v2) {
      var rows = F.lookuprows(de, k1, v1, k2, v2);
      return rows.length ? toStr(rows[0][col]) : '';
    };
    F.lookuprows = function (de, k1, v1, k2, v2) {
      var tbl = ctx.data[de] || [];
      return tbl.filter(function (r) {
        if (k1 !== undefined && String(r[k1]) !== String(v1)) return false;
        if (k2 !== undefined && String(r[k2]) !== String(v2)) return false;
        return true;
      });
    };
    F.lookuporderedrows = function (de, count, orderBy, k1, v1) {
      var rows = F.lookuprows(de, k1, v1).slice();
      if (orderBy) {
        var parts = String(orderBy).trim().split(/\s+/);
        var col = parts[0], desc = (parts[1] || '').toUpperCase() === 'DESC';
        rows.sort(function (a, b) {
          var x = a[col], y = b[col];
          if (x === y) return 0;
          return (x > y ? 1 : -1) * (desc ? -1 : 1);
        });
      }
      return count > 0 ? rows.slice(0, count) : rows;
    };
    F.row = function (rows, i) { return (rows || [])[(i || 1) - 1] || {}; };
    F.field = function (row, name) { return row && row[name] !== undefined ? row[name] : ''; };
    F.rowcount = function (rows) { return (rows || []).length; };
    F.empty = function (v) { return v === null || v === undefined || String(v) === ''; };
    F.trim = function (v) { return toStr(v).trim(); };
    F.propercase = function (v) {
      return toStr(v).toLowerCase().replace(/(^|[\s'-])([a-z])/g, function (m, a, b) { return a + b.toUpperCase(); });
    };
    F.uppercase = function (v) { return toStr(v).toUpperCase(); };
    F.lowercase = function (v) { return toStr(v).toLowerCase(); };
    F.concat = function () { return [].map.call(arguments, toStr).join(''); };
    F.length = function (v) { return toStr(v).length; };
    F.substring = function (v, start, len) {
      var s = toStr(v), i = Math.max(0, (start || 1) - 1);
      return len === undefined ? s.substring(i) : s.substr(i, len);
    };
    F.indexof = function (hay, needle) { return toStr(hay).indexOf(toStr(needle)) + 1; };
    F.replace = function (s, a, b) { return toStr(s).split(toStr(a)).join(toStr(b)); };
    F.iif = function (c, a, b) { return truthy(c) ? a : b; };
    F.formatdate = function (d, pattern) { return fmtDate(d, pattern); };
    F.formatnumber = function (v, pattern) {
      var n = toNum(v), p = String(pattern || '');
      if (/^N0$/i.test(p)) return Math.round(n).toLocaleString('en-US');
      if (/^N2$/i.test(p)) return n.toLocaleString('en-US', { minimumFractionDigits: 2, maximumFractionDigits: 2 });
      if (/^C$/i.test(p)) return '$' + n.toLocaleString('en-US', { minimumFractionDigits: 2, maximumFractionDigits: 2 });
      if (/^P/i.test(p)) return (n * 100).toFixed(0) + '%';
      return String(n);
    };
    F.now = function () { return ctx.now; };
    F.datediff = function (a, b, part) {
      var d1 = parseDate(a), d2 = parseDate(b), ms = d2 - d1;
      var p = String(part || 'D').toUpperCase();
      if (p === 'Y') return d2.getFullYear() - d1.getFullYear();
      if (p === 'M') return (d2.getFullYear() - d1.getFullYear()) * 12 + (d2.getMonth() - d1.getMonth());
      if (p === 'H') return Math.floor(ms / 3600000);
      if (p === 'MI') return Math.floor(ms / 60000);
      return Math.floor(ms / 86400000);
    };
    F.dateadd = function (d, amount, part) {
      var x = new Date(parseDate(d).getTime()), p = String(part || 'D').toUpperCase(), a = toNum(amount);
      if (p === 'Y') x.setFullYear(x.getFullYear() + a);
      else if (p === 'M') x.setMonth(x.getMonth() + a);
      else if (p === 'H') x.setHours(x.getHours() + a);
      else x.setDate(x.getDate() + a);
      return x;
    };
    F.add = function (a, b) { return toNum(a) + toNum(b); };
    F.subtract = function (a, b) { return toNum(a) - toNum(b); };
    F.multiply = function (a, b) { return toNum(a) * toNum(b); };
    F.divide = function (a, b) { return toNum(b) === 0 ? 0 : toNum(a) / toNum(b); };
    F.mod = function (a, b) { return toNum(b) === 0 ? 0 : toNum(a) % toNum(b); };
    F.attributevalue = function (name) {
      var v = ctx.subscriber[name];
      return v === undefined ? '' : v;
    };
    F.urlencode = function (v) { return encodeURIComponent(toStr(v)); };
    F.redirectto = function (v) { return toStr(v); };
    return F;
  }

  /* ----------------------------------------------------------- evaluator */
  function Interp(ctx) {
    this.ctx = ctx;
    this.vars = {};
    this.fns = makeFns(ctx);
    this.trace = [];
  }
  /* Keys are stored without the leading @ and lower-cased, so @FirstName,
     @firstname and a later read of vars.firstname all reach the same slot. */
  function vkey(name) { return String(name).replace(/^@/, '').toLowerCase(); }

  Interp.prototype.get = function (name) {
    var v = this.vars[vkey(name)];
    return v === undefined ? '' : v;
  };
  Interp.prototype.set = function (name, val) {
    this.vars[vkey(name)] = val;
    this.trace.push({ name: name, value: val });
  };

  Interp.prototype.evalExpr = function (n) {
    switch (n.t) {
      case 'lit': return n.v;
      case 'ref': return this.get(n.name);
      case 'not': return !truthy(this.evalExpr(n.e));
      case 'bin': {
        var op = n.op;
        if (op === 'AND') return truthy(this.evalExpr(n.l)) && truthy(this.evalExpr(n.r));
        if (op === 'OR') return truthy(this.evalExpr(n.l)) || truthy(this.evalExpr(n.r));
        var a = this.evalExpr(n.l), b = this.evalExpr(n.r);
        switch (op) {
          case '==': return String(a) === String(b);
          case '!=': case '<>': return String(a) !== String(b);
          case '>': return toNum(a) > toNum(b);
          case '>=': return toNum(a) >= toNum(b);
          case '<': return toNum(a) < toNum(b);
          case '<=': return toNum(a) <= toNum(b);
          case '+': return (typeof a === 'number' && typeof b === 'number') ? a + b : toStr(a) + toStr(b);
          case '-': return toNum(a) - toNum(b);
        }
        return '';
      }
      case 'call': {
        var f = this.fns[n.name.toLowerCase()];
        var args = n.args.map(this.evalExpr, this);
        if (!f) throw new Error('Unsupported function: ' + n.name + '()');
        return f.apply(null, args);
      }
    }
    return '';
  };

  Interp.prototype.run = function (stmts) {
    for (var i = 0; i < stmts.length; i++) {
      var s = stmts[i];
      if (s.t === 'set') { this.set(s.name, this.evalExpr(s.expr)); }
      else if (s.t === 'expr') { this.evalExpr(s.expr); }
      else if (s.t === 'if') {
        var done = false;
        for (var b = 0; b < s.branches.length; b++) {
          if (truthy(this.evalExpr(s.branches[b].cond))) { this.run(s.branches[b].body); done = true; break; }
        }
        if (!done && s.els) this.run(s.els);
      }
      else if (s.t === 'for') {
        var from = toNum(this.evalExpr(s.from)), to = toNum(this.evalExpr(s.to));
        var step = s.dir === 'DOWNTO' ? -1 : 1, guard = 0;
        for (var v = from; step > 0 ? v <= to : v >= to; v += step) {
          this.set(s.v, v);
          this.run(s.body);
          if (++guard > 1000) break;
        }
      }
    }
  };

  /* ------------------------------------------------------------- template */
  /*
    AMPscript control flow wraps HTML: an IF opened in one %%[ ]%% block
    closes in a later one, and the markup between them is what gets gated.
    So the template is not evaluated block by block. It is first flattened
    into ONE program -- literal HTML becomes __emit(n), %%=expr=%% becomes
    __out(expr), and block code is spliced in as-is -- then parsed and run
    as a single statement tree. That is what makes
        %%[ IF @x THEN ]%% <p>A</p> %%[ ELSE ]%% <p>B</p> %%[ ENDIF ]%%
    emit one paragraph instead of both.
  */
  function flatten(template) {
    var parts = [], src = '', i = 0;

    function emitText(txt) {
      if (!txt) return;
      parts.push(txt);
      src += '\n__emit(' + (parts.length - 1) + ')\n';
    }

    while (i < template.length) {
      var b = template.indexOf('%%[', i);
      var n = template.indexOf('%%=', i);
      if (b === -1 && n === -1) { emitText(template.slice(i)); break; }

      var isBlock = b !== -1 && (n === -1 || b < n);
      var start = isBlock ? b : n;
      emitText(template.slice(i, start));

      if (isBlock) {
        var e = template.indexOf(']%%', start);
        if (e === -1) { emitText(template.slice(start)); break; }
        src += '\n' + template.slice(start + 3, e) + '\n';
        i = e + 3;
      } else {
        var e2 = template.indexOf('=%%', start);
        if (e2 === -1) { emitText(template.slice(start)); break; }
        var expr = template.slice(start + 3, e2).trim();
        if (/^v\s*\(/i.test(expr)) expr = expr.replace(/^v\s*\(/i, '(');
        src += '\n__out(' + expr + ')\n';
        i = e2 + 3;
      }
    }
    return { src: src, parts: parts };
  }

  function render(template, ctx) {
    var flat = flatten(template);
    var interp = new Interp(ctx);
    var buf = [];

    interp.fns.__emit = function (idx) { buf.push(flat.parts[idx]); return ''; };
    interp.fns.__out  = function (v) { buf.push(toStr(v)); return ''; };

    var errors = [];
    try {
      interp.run(new Parser(tokenize(flat.src)).parseBlock([]));
    } catch (e) {
      errors.push(e.message);
    }
    return { html: buf.join(''), vars: interp.vars, trace: interp.trace, errors: errors };
  }

  global.MiniAmp = { render: render, tokenize: tokenize, Parser: Parser };
})(window);

sfmc/journeys/simulator.js
/*
  ==========================================================================
  JOURNEY BUILDER SIMULATOR
  Author: Faisal Irfan | github.com/faisal8143
  --------------------------------------------------------------------------
  Walks one contact through the journey model, evaluating each activity the
  way Journey Builder would and recording WHY every decision went as it did.

  The part people get wrong in interviews: goal and exit criteria are checked
  continuously, not at the end. A contact who meets the goal inside a wait
  leaves the journey there and never receives the rest of the sends. The
  stepper below models that, which is why Priya exits mid-wait on day 6.
  ==========================================================================
*/
(function () {
  'use strict';
  var J = window.JOURNEY;

  var NODE = {};
  J.nodes.forEach(function (n) { NODE[n.id] = n; });

  function edgesFrom(id) { return J.edges.filter(function (e) { return e.from === id; }); }

  function fmt(h) {
    if (h < 1) return 'start';
    if (h < 24) return 'hour ' + Math.round(h);
    var d = h / 24;
    return 'day ' + (d % 1 === 0 ? d : d.toFixed(1));
  }

  /* --------------------------------------------------------------------
     Build the full step list for one contact.
     Each step: node, hour, status, reason.
     -------------------------------------------------------------------- */
  function simulate(contact) {
    var steps = [];
    var hour = 0;
    var id = 'entry';
    var sent = [];
    var guard = 0;

    /* Events that cut the journey short, checked between every activity */
    function interrupt(fromHour, toHour) {
      var hit = null;
      contact.events.forEach(function (ev) {
        if (ev.afterHours <= fromHour || ev.afterHours > toHour) return;
        if (ev.type === 'goal' || ev.type === 'unsubscribe') {
          if (!hit || ev.afterHours < hit.afterHours) hit = ev;
        }
      });
      return hit;
    }

    function opened(emailId, byHour, windowHours) {
      var sentAt = sent[emailId];
      if (sentAt === undefined) return null;
      var found = null;
      contact.events.forEach(function (ev) {
        if (ev.of !== emailId) return;
        if (ev.type !== 'open' && ev.type !== 'click') return;
        if (ev.afterHours < sentAt || ev.afterHours > byHour) return;
        if (!found || ev.afterHours < found.afterHours) found = ev;
      });
      return found;
    }

    while (id && guard++ < 40) {
      var n = NODE[id];

      if (n.type === 'wait') {
        var until = hour + n.hours;
        var cut = interrupt(hour, until);
        if (cut) {
          steps.push({
            node: n.id, hour: hour, status: 'wait',
            reason: 'Waiting ' + n.label + '. Goal and exit criteria stay live during a wait.'
          });
          steps.push({
            node: cut.type === 'goal' ? 'goal' : 'exit',
            hour: cut.afterHours,
            status: cut.type === 'goal' ? 'goal' : 'exit',
            reason: cut.type === 'goal'
              ? cut.note + ' on ' + fmt(cut.afterHours) + '. Goal met, so the contact exits here and receives nothing further.'
              : cut.note + ' on ' + fmt(cut.afterHours) + '. Exit criteria met, journey ends.'
          });
          return steps;
        }
        steps.push({
          node: n.id, hour: hour, status: 'done',
          reason: 'Waited ' + n.label + ', resuming at ' + fmt(until) + '.'
        });
        hour = until;
        id = (edgesFrom(id)[0] || {}).to;
        continue;
      }

      if (n.type === 'entry') {
        steps.push({
          node: n.id, hour: 0, status: 'done',
          reason: 'Entered from Course_Enquiries with ' + contact.attributes.CourseName +
                  ' and EngagementScore ' + contact.attributes.EngagementScore + '.'
        });
        id = (edgesFrom(id)[0] || {}).to;
        continue;
      }

      if (n.type === 'email') {
        sent[n.id] = hour;
        steps.push({
          node: n.id, hour: hour, status: 'done',
          reason: 'Sent "' + n.label + '" on ' + fmt(hour) + '.'
        });
        id = (edgesFrom(id)[0] || {}).to;
        continue;
      }

      if (n.type === 'engagement') {
        var ev = opened('email1', hour, 72);
        var yes = !!ev;
        steps.push({
          node: n.id, hour: hour, status: yes ? 'yes' : 'no',
          reason: yes
            ? 'Opened Email 1 on ' + fmt(ev.afterHours) + ', inside the 3-day window, so the contact takes the engaged path.'
            : 'No open on Email 1 within 3 days, so the contact takes the re-engagement path. The window matters: an open on day 4 arrives after the split has already evaluated.'
        });
        var e = edgesFrom(n.id).filter(function (x) { return x.path === (yes ? 'yes' : 'no'); })[0];
        id = e && e.to;
        continue;
      }

      if (n.type === 'decision') {
        var score = contact.attributes.EngagementScore;
        var hot = score >= 40;
        steps.push({
          node: n.id, hour: hour, status: hot ? 'yes' : 'no',
          reason: 'EngagementScore is ' + score + '. ' + (hot
            ? 'At or above 40, so the contact is routed to the hot path.'
            : 'Below 40, so the contact continues on the warm nurture path.') +
            ' A decision split reads the attribute as it stands at this moment, not at entry.'
        });
        var e2 = edgesFrom(n.id).filter(function (x) { return x.path === (hot ? 'yes' : 'no'); })[0];
        id = e2 && e2.to;
        continue;
      }

      if (n.type === 'update') {
        steps.push({
          node: n.id, hour: hour, status: 'done',
          reason: 'Created a Sales Cloud task and sent the advisor SMS. Advisor calls within 24 hours.'
        });
        id = (edgesFrom(id)[0] || {}).to;
        continue;
      }

      id = (edgesFrom(id)[0] || {}).to;
    }

    steps.push({
      node: 'end', hour: hour, status: 'end',
      reason: 'Reached the end of the journey without meeting the goal. Exits automatically after ' +
              J.exitAfterDays + ' days.'
    });
    return steps;
  }

  window.simulateJourney = simulate;
  window.JOURNEY_NODE = NODE;
  window.journeyEdgesFrom = edgesFrom;
  window.journeyFmtHour = fmt;
})();

# Marketing Cloud Next: readiness audit

**Author:** Faisal Irfan · [github.com/faisal8143](https://github.com/faisal8143)
**Last reviewed:** November 2026 · Salesforce Certified Marketing Cloud Next Consultant

What this is: the inventory and the decisions I work through before anyone
commits to a Marketing Cloud Next migration date. The point of an audit is to
find out what has to be rebuilt *before* the budget is set, not after.

A caveat I keep in the document rather than hiding: Marketing Cloud Next is
moving quickly, and some mappings below are not yet settled in Salesforce's
own documentation. Those are marked **verify**. An audit that presents
unsettled things as settled is worse than no audit.

---

## 1. What the platform change actually is

Classic Marketing Cloud is a standalone application with its own data store
(Data Extensions), its own scripting (AMPscript, SSJS), its own query engine
(SQL on data views) and its own orchestration (Journey Builder, Automation
Studio).

Marketing Cloud Next sits on the Salesforce core platform. Data lives in
Data Cloud rather than in Data Extensions, audiences are segments rather than
SQL query activities, and orchestration moves to Flow.

The practical consequence: this is not a version upgrade. Content and logic
are portable in principle, but the data layer underneath them is a different
model, and most of the migration effort lands there.

## 3. Personalisation, side by side

The same fallback, written both ways.

**AMPscript**

```
SET @firstName = AttributeValue("FirstName")
IF Empty(@firstName) THEN
  SET @firstName = "there"
ELSE
  SET @firstName = ProperCase(Trim(@firstName))
ENDIF
```

**Marketing Cloud Next (Handlebars)**

```
{{fallback (get (get @root "$dataGraph") "ssot__FirstName__c") "there"}}
```

What this tells you about the migration:

- The **logic** transfers. Conditions, fallbacks and data relationships are
  the same problems, expressed differently.
- The **data access** does not. `Lookup("DE", "Field", "Key", @value)` assumes
  a table you query. `get` walks a graph already assembled around the person.
  A template full of lookups is not a find-and-replace job; the data has to
  exist on the graph first.
- Complexity moves **upstream**. Work AMPscript used to do at send time —
  joining, deduplicating, picking the latest row — belongs in the data model
  and the segment before the send.

## 5. Decisions to make before any build starts

These are the ones that are expensive to reverse:

| Decision | Why it is hard to undo |
| --- | --- |
| Org strategy | Which Salesforce org Marketing Cloud Next runs in shapes everything downstream |
| Real-time vs batch per source | A data stream's refresh mode cannot be changed after creation |
| Identity resolution rules | These decide who counts as the same person; changing them later re-resolves the whole profile base |
| Consent model | Must be mapped before any contact is imported, not after |
| Channel and credit model | Email, SMS and WhatsApp are tracked and billed differently |
| Environment plan | Where testing happens, and how changes get promoted |

## 6. What the output looks like

A readiness audit should end with three things, not an opinion:

1. **An inventory** — every asset, categorised as portable, rebuild, or retire.
2. **A risk register** — what breaks if it is migrated as-is, ranked.
3. **A phased roadmap** — what moves first, what runs in parallel, and for how
   long both platforms have to coexist.

The honest finding on most audits is that a chunk of the estate should be
retired rather than migrated. Templates nobody sends, automations that failed
silently for a year, DEs with no writer. Migrating those costs real money and
buys nothing.

  • First-touch attribution persists across funnel steps in sessionStorage
  • Listens for GHL's postMessage submit event and pushes a GA4/Ads conversion to the dataLayer

ghl/js/ghl-attribution-and-forms.js
/*
  ==========================================================================
  NORTHWIND LEARNING | GOHIGHLEVEL ATTRIBUTION + FORM ENHANCEMENTS
  Author: Faisal Irfan | github.com/faisal8143
  --------------------------------------------------------------------------
  Paste into: Funnel > Settings > Tracking Code > Footer.

  Solves the four things GHL funnels lose by default:

    1. ATTRIBUTION SURVIVES THE FUNNEL
       GHL embeds forms in an iframe, so utm_* parameters on the parent URL
       never reach the form. They are also lost on step 2 of any funnel.
       Fixed by persisting first-touch values and appending them to every
       form iframe src on the page.

    2. NO DOUBLE SUBMITS
       The native submit button stays live while the request is in flight,
       so an impatient click creates duplicate contacts and fires the
       workflow twice.

    3. SUBMISSION EVENTS REACH GTM
       GHL posts a message to the parent window on submit, but nothing
       listens, so GA4/Ads conversions never fire from a funnel step.

    4. SCROLL + ENGAGEMENT SIGNAL
       Pushes a single qualified-engagement event so CRO tests have a
       secondary metric when conversion volume is thin.

  Dependencies: none. Safe to load on every funnel step.
  ==========================================================================
*/
(function () {
  'use strict';

  var CONFIG = {
    storageKey: 'nw_attr',
    /* Parameters mapped to GHL custom fields of the same name */
    params: ['utm_source', 'utm_medium', 'utm_campaign', 'utm_term', 'utm_content',
             'gclid', 'fbclid', 'msclkid', 'ttclid'],
    /* First touch wins: a visitor who arrives on paid then returns direct
       should still be attributed to the paid click */
    firstTouch: true,
    formSelector: 'iframe[src*="leadconnectorhq.com"], iframe[src*="msgsndr.com"], iframe.ghl-form-iframe',
    engagementDepth: 0.5,     // fraction of the page scrolled
    engagementSeconds: 20
  };

  /* ---------------------------------------------------------------------
     1. Capture and persist attribution
     --------------------------------------------------------------------- */

  function readStore() {
    try { return JSON.parse(sessionStorage.getItem(CONFIG.storageKey)) || {}; }
    catch (e) { return {}; }
  }

  function writeStore(data) {
    try { sessionStorage.setItem(CONFIG.storageKey, JSON.stringify(data)); } catch (e) {}
  }

  function collect() {
    var qs = new URLSearchParams(window.location.search);
    var stored = readStore();
    var out = {};

    CONFIG.params.forEach(function (key) {
      var fresh = qs.get(key);
      if (CONFIG.firstTouch) {
        out[key] = stored[key] || fresh || '';
      } else {
        out[key] = fresh || stored[key] || '';
      }
    });

    /* Referrer is only meaningful on the entry page of the session */
    out.referrer = stored.referrer ||
      (document.referrer && document.referrer.indexOf(location.hostname) === -1 ? document.referrer : 'direct');
    out.landing_page = stored.landing_page || location.href.split('#')[0];

    writeStore(out);
    return out;
  }

  var attribution = collect();

  /* ---------------------------------------------------------------------
     2. Push attribution into every GHL form iframe
     GHL reads query parameters off the iframe src and maps them onto
     custom fields with matching keys.
     --------------------------------------------------------------------- */

  function decorate(iframe) {
    if (iframe.dataset.nwDecorated) return;

    var src = iframe.getAttribute('src');
    if (!src) return;

    var url;
    try { url = new URL(src, location.origin); } catch (e) { return; }

    var added = false;
    Object.keys(attribution).forEach(function (key) {
      if (attribution[key] && !url.searchParams.has(key)) {
        url.searchParams.set(key, attribution[key]);
        added = true;
      }
    });

    iframe.dataset.nwDecorated = '1';
    /* Only reload the iframe when something actually changed */
    if (added) iframe.setAttribute('src', url.toString());
  }

  function decorateAll() {
    document.querySelectorAll(CONFIG.formSelector).forEach(decorate);
  }

  decorateAll();

  /* GHL injects forms after page load and on step transitions */
  if (window.MutationObserver) {
    new MutationObserver(decorateAll).observe(document.documentElement, {
      childList: true,
      subtree: true
    });
  }

  /* Carry attribution onto internal links so the next funnel step keeps it
     even if sessionStorage is blocked */
  document.addEventListener('click', function (e) {
    var a = e.target.closest && e.target.closest('a[href]');
    if (!a) return;
    var href = a.getAttribute('href');
    if (!href || href.charAt(0) === '#' || /^(mailto|tel):/.test(href)) return;

    var url;
    try { url = new URL(href, location.href); } catch (err) { return; }
    if (url.hostname !== location.hostname) return;

    CONFIG.params.forEach(function (key) {
      if (attribution[key] && !url.searchParams.has(key)) url.searchParams.set(key, attribution[key]);
    });
    a.setAttribute('href', url.toString());
  }, true);

  /* ---------------------------------------------------------------------
     3. Double-submit guard on native GHL forms rendered inline
     --------------------------------------------------------------------- */

  document.addEventListener('submit', function (e) {
    var form = e.target;
    if (!form.matches('.hl_form-builder, .ghl-form, form[data-ghl]')) return;

    if (form.dataset.nwSubmitting === '1') {
      e.preventDefault();
      e.stopImmediatePropagation();
      return;
    }
    form.dataset.nwSubmitting = '1';

    var btn = form.querySelector('button[type="submit"], input[type="submit"]');
    if (btn) {
      btn.disabled = true;
      btn.dataset.nwLabel = btn.textContent;
      btn.textContent = 'Sending…';
    }

    /* Release after 12s so a failed request does not strand the visitor */
    setTimeout(function () {
      form.dataset.nwSubmitting = '';
      if (btn) {
        btn.disabled = false;
        if (btn.dataset.nwLabel) btn.textContent = btn.dataset.nwLabel;
      }
    }, 12000);
  }, true);

  /* ---------------------------------------------------------------------
     4. Relay GHL's iframe submission message to the data layer
     --------------------------------------------------------------------- */

  window.addEventListener('message', function (event) {
    if (!/leadconnectorhq\.com|msgsndr\.com/.test(event.origin)) return;

    var data = event.data;
    if (typeof data === 'string') {
      try { data = JSON.parse(data); } catch (e) { return; }
    }
    if (!data || !data.type) return;

    if (data.type === 'form-submitted' || data.type === 'hl_form_submit') {
      window.dataLayer = window.dataLayer || [];
      window.dataLayer.push({
        event: 'generate_lead',
        form_id: data.formId || '',
        funnel_step: document.body.dataset.step || location.pathname,
        utm_source: attribution.utm_source || '',
        utm_campaign: attribution.utm_campaign || ''
      });
    }

    /* GHL sends the iframe's rendered height; without this the form is
       cut off on mobile whenever a validation message appears */
    if (data.type === 'resize' && data.height) {
      document.querySelectorAll(CONFIG.formSelector).forEach(function (f) {
        if (f.contentWindow === event.source) f.style.height = data.height + 'px';
      });
    }
  }, false);

  /* ---------------------------------------------------------------------
     5. Qualified engagement, fired once
     --------------------------------------------------------------------- */

  (function engagement() {
    var fired = false, deep = false, stayed = false;

    function maybe() {
      if (fired || !deep || !stayed) return;
      fired = true;
      window.dataLayer = window.dataLayer || [];
      window.dataLayer.push({ event: 'qualified_engagement', page: location.pathname });
    }

    setTimeout(function () { stayed = true; maybe(); }, CONFIG.engagementSeconds * 1000);

    window.addEventListener('scroll', function onScroll() {

# Make.com scenario: GoHighLevel lead enrichment and routing

**Author:** Faisal Irfan · [github.com/faisal8143](https://github.com/faisal8143)
**Brand:** Northwind Learning (fictional, for demonstration)

The problem this solves: GHL workflows are good at sequencing, and poor at
anything that needs a lookup, a conditional join, or a second system. Running
enrichment inside Make keeps the GHL workflow readable and puts the branching
logic where it can be tested without re-triggering a live contact.

---

## Trigger

**Module:** `Webhooks → Custom webhook` — `nw-ghl-new-lead`

Fired by a GHL workflow action (*Webhook → POST*) on the **Contact Created**
and **Form Submitted** triggers.

```json
{
  "contact_id": "{{contact.id}}",
  "email": "{{contact.email}}",
  "phone": "{{contact.phone}}",
  "first_name": "{{contact.first_name}}",
  "field_of_study": "{{contact.field_of_study}}",
  "utm_source": "{{contact.utm_source}}",
  "utm_campaign": "{{contact.utm_campaign}}",
  "gclid": "{{contact.gclid}}",
  "form_variant": "{{contact.form_variant}}",
  "stage": "{{contact.stage}}"
}
```

---

## Steps

| # | Module | What it does |
| --- | --- | --- |
| 1 | Webhook | Receives the payload above |
| 2 | Tools → Set variables | Normalises email to lowercase, strips spaces from phone, converts the phone to E.164 using the country from the GHL location |
| 3 | Router | Splits on `stage` — `partial` and `complete` take different paths |
| 4a | HTTP → Make a request | Email verification API; writes `email_valid` and `email_risk` back as custom fields |
| 4b | Google Sheets → Search rows | Course catalogue lookup on `field_of_study`, returning the advisor who owns that field |
| 5 | GoHighLevel → Update contact | Writes `advisor_owner`, `email_valid`, `lead_score` |
| 6 | GoHighLevel → Add tag | `course-{{field_of_study}}` plus `paid` or `organic` from `utm_source` |
| 7 | Filter | Only continues when `email_valid = true` and `stage = complete` |
| 8 | GoHighLevel → Add to workflow | Routes into the matching nurture sequence |
| 9 | Slack → Create a message | Posts high-intent leads (score ≥ 40) into `#admissions` for same-day follow-up |
| 10 | Error handler | On any failure, writes the payload to a Google Sheet and posts to `#integration-errors` so nothing is silently dropped |

---

## Scoring logic (step 5)

Scored inside a Make `Tools → Set variable` rather than in GHL, so the rule
is one expression instead of ten workflow branches:

```
{{
  ( if(1.utm_source = "google"; 20; if(1.utm_source = "meta"; 10; 5)) ) +
  ( if(1.gclid != emptystring; 15; 0) ) +
  ( if(1.field_of_study = "Still deciding"; 0; 15) ) +
  ( if(1.phone != emptystring; 10; 0) )
}}
```

| Score | Band | Routing |
| --- | --- | --- |
| 40+ | Hot | Slack alert, advisor calls same day, 3-step SMS sequence |
| 20–39 | Warm | 5-email nurture, call attempt at day 3 |
| Under 20 | Cold | Monthly newsletter only |

---

## Notes from running this in production

- **Make the webhook idempotent.** GHL retries a failed webhook, and without
  a dedupe on `contact_id` + `stage` you get two Slack pings and a doubled
  score. A data store with a 10-minute TTL key handles it.
- **Never write back into a field the GHL workflow also writes.** Two systems
  owning one field produces a race that only shows up under load.
- **Partials are worth capturing.** Step-1 emails that never finish step 2
  convert at a meaningful rate on a single reminder email, and they only
  exist because the form fires at step 1.
- **Watch the operations count.** The router doubling every branch is the
  usual cause of a plan running out mid-month; filters belong before the
  router, not after it.
